
# DTI — موقع ثابت (نسخة أكاديمية محسّنة)

نسخة محسّنة من الواجهة الرئيسية بتصميم أكاديمي: تحسين الطباعة، لوح ألوان رسمي، ومخططات قابلة للطباعة.

تشغيل محليًا:

```bash
cd /workspaces/dti
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

ملفات رئيسية:
- [index.html](index.html) — الصفحة الرئيسية الجديدة
- [styles.css](styles.css) — أنماط التصميم الأكاديمي
-- assets/img-5.svg — شعار مبسّط (أعيد تسميته)

نشر على GitHub Pages: ادفع إلى الفرع `main` وفعل GitHub Pages في إعدادات المستودع (مصدر: فرع `main`، المسار: `/`).

عرض مؤرشف للموقع الأصلي:
- `original.html` — نسخة خام كاملة (تحوي HTML الأصلية).
- `original_view.html` — عرض منقّح يستخدم `content/body_clean.html` (أزِلنا الـ iframes والـ scripts لعرض ثابت).

الخطوات القادمة التي أقترحها:
- استحضار النصوص والصور من موقعك الأصلي ومطابقة الألوان بدقة.
- إضافة صفحات فرعية (تفاصيل البرامج، نماذج تواصل، مكتبة منشورات قابلة للتحميل).

أخبرني إذا تودّ أن أُجري تعديلات إضافية تلقائياً (تنظيف الصور، استبدال الـ iframes بمقتطفات ثابتة، تحسين التباين، أو تجهيز فرع `gh-pages`).
